# howware.org

Source of [howware.org](https://howware.org), the site of the howware organization. Published with GitHub Pages
from the root of `main`.

The concept, manifesto, whitepaper, specification, skills and template live in
[howware/howware](https://github.com/howware/howware). Each project's own site is served under its path:
[howware.org/finanzas-personales](https://howware.org/finanzas-personales/),
[howware.org/mx-bank-statement-reader](https://howware.org/mx-bank-statement-reader/),
[howware.org/long-term-memory-for-AI](https://howware.org/long-term-memory-for-AI/).
